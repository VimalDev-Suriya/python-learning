# Numerical Python (NumPy):

- A Open source library to handle the complex numerical calculations.
- Its the base of the python's data science ecosystem
- Very efficient in working with large, multi-dimentional arrays and Matrices.

**Note**: Always give the file name different from the package name. Or else we will get the circular dependency error.

## Core Features:
- The Numpy has the `ndarray` [n-dimentional-array]
- The Array structure should be Homogenous - should be same.
